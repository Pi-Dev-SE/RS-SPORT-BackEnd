## 📖 Description

This is the **backend API** for the **RS SPORT** web application. It is built using **Spring Boot** and provides RESTful endpoints for managing players, teams, performance tracking, medical reports, and more. It handles data persistence, business logic, security, and API integration with the Angular frontend.

## 🚀 Features

- 📋 CRUD operations for players, teams, health reports, and performance
- 🔒 JWT-based authentication and role-based access control
- 📊 API endpoints for performance tracking and injury statistics
- 💾 Database integration ( MySQL)
- 🌐 CORS configuration for frontend communication
- 📂 File upload (e.g., medical documents, player photos)
